# モルックモンスター 緑

ブラウザで遊べる、ゲームボーイ風の緑色モンスター育成RPGです。
町を歩く → 草むらで野生の「モルモン」と出会う → ターン制バトル → モルックをなげて捕まえる → 仲間にする。
主人公は「左手の勇者」（モルックチーム「かみだのみ」の選手）です。

版：v0.1.6

## 遊び方

- スマホ：画面のボタンで操作します（十字キーで歩く、Aで決定・話す、Bで戻る、MENUでメニュー）。
- パソコン：

| 操作 | キー |
|---|---|
| 歩く | 矢印キー / WASD |
| 決定・話す・調べる | Z / Enter / Space |
| 戻る・キャンセル | X / Esc / Backspace |
| メニューを開く | Shift / Q |

- 音（BGM）は、最初に1回タップ（またはキー入力）すると鳴ります。MENU の「おと」でオン/オフを切り替えられます。
- セーブはメニューの「セーブ」から。ブラウザの中に保存されます。

## メモ

- 画像・音声ファイルは使わず、すべてプログラムで描いたり作ったりしています。
- 文字フォント DotGothic16 は Google Fonts から読み込みます（ネットにつながらないときは別のフォントになります）。
